# Combined runtime search checkpoint

[Acceptance](acceptance.json) records a successful three-iteration search through the actual coding proposer, Docker strategies and normal Omnigent/MCP runtime. Seven development and seven private final evaluations used authored model/source responses. The totals are 125 requests, 13,750 synthetic tokens and 157 actual Docker executions. These results establish software behavior, not measured optimization gains.

[Verification](verification.json) records the reproduction command, six passing helper tests, lint/format results and executed source hashes. The [fresh-process audit](independent-audit.json) verifies bindings, sealed proposer attempts, raw proposer usage and strategy sessions. The earlier 985-test suite remains a separate dated checkpoint.

The [archive index](index.json) gives the SHA-256 of every payload in `artifacts.tar.gz`:

- `development-feedback/`: complete exported development artifacts and candidate bundles.
- `search/proposal-inputs/`: the exact feedback snapshots each proposer received.
- `search/proposals/`: complete closed attempts, raw gateway requests/responses, filesystem tool results, candidate programs and actual Docker checks.
- `search/interfaces/` and `search/candidate-attempts/`: public contract executions and submitted candidate artifacts.
- `baseline/`: original strategy and instructions.
- `checkpoint-source/`: executed implementation/example source and current test source for reproduction.
- `host-metadata/`: an explicitly labeled journal excerpt omitting private final results; its original digest is retained.

Private final packages and execution contents are retained only in the local run directory. The separate ten-case private benchmark draft and native runtime credentials are excluded. Only the original development feedback snapshots are valid proposer inputs; reproduction source and host metadata are for reviewers.

All seven development candidates tied at quality 1.0 and 770 synthetic tokens, leaving all seven on the development frontier. Selection and permanent proposer revocation preceded final package creation. Repeating completed final/controller operations executed no further requests. Independent human review and measured model runs remain outstanding.
