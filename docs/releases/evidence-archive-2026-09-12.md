This is a **test-evidence archive for code reviewers**, not an application release.

It contains saved test runs from development of Research Harness's data collection
and agent integration. Model responses in those runs were scripted. The archive
does not demonstrate live model quality or improved research performance.

**Want to use Research Harness?** Follow the
[README](https://github.com/Madhavan113/researchharness#research-harness)
to install and run the current CLI from source. You do not need these downloads.

## Downloads

| File | Size | Contents |
| --- | --- | --- |
| `artifacts.tar.gz` | 24.4 MB | Test logs, saved responses, runtime snapshots and review manifests |
| `files.json.gz` | 604 KB | Compressed file inventory with checksums and provenance |

The archive is intended for inspecting past tests. It is not a runnable demo,
application backup or ready-to-use research dataset. GitHub's automatically
generated source-code downloads refer to this historical checkpoint.
